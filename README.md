# สมุดบ้าน — คู่มือติดตั้ง (รุ่นแรก)

## ไฟล์ในโปรเจกต์
- `index.html` — ตัวเว็บแอปทั้งหมด (สมัคร, ล็อกอิน, สร้าง/เข้าร่วมบ้าน, บันทึกรายรับรายจ่าย, สรุปรายเดือน)
- `schema.sql` — โครงฐานข้อมูล + ระบบล็อกข้อมูลแยกแต่ละบ้าน (RLS)

เปิด `index.html` ได้ทันทีโดยไม่ต้องตั้งค่าอะไร จะเข้า **โหมดทดลอง** (ข้อมูลหายเมื่อรีเฟรช) ไว้ดูหน้าตาและลองใช้

## ขั้นตอนใช้งานจริง

1. **สร้างโปรเจกต์ Supabase** ที่ supabase.com → New project (เลือก Region: Singapore จะเร็วสุดสำหรับไทย)
2. **สร้างตาราง**: เมนู SQL Editor → New query → วางเนื้อหาทั้งไฟล์ `schema.sql` → Run
3. **ปิดการยืนยันอีเมล**: Authentication → Sign In / Providers → Email → ปิด *Confirm email* → Save
4. **คัดลอกค่าเชื่อมต่อ**: Project Settings → API → คัดลอก *Project URL* และ *anon public key*
   แล้ววางในส่วน `CONFIG` ด้านบนของ `<script>` ใน `index.html`
5. **ขึ้นเว็บ**: ลากโฟลเดอร์ไปวางที่ app.netlify.com/drop หรือใช้ Vercel / Cloudflare Pages ได้ฟรี
6. **ตั้ง URL**: Supabase → Authentication → URL Configuration → ใส่ URL เว็บที่ได้จากข้อ 5 ใน Site URL

## ทดสอบหลังติดตั้ง
- สมัครบัญชี A → สร้างบ้าน → จดรหัสเชิญ
- เปิดเบราว์เซอร์อีกตัว (หรือโหมดไม่ระบุตัวตน) สมัครบัญชี B → เข้าร่วมด้วยรหัสเชิญ
- บันทึกรายการจากทั้งสองบัญชี แล้วดูว่าเห็นตรงกัน
- สมัครบัญชี C สร้างบ้านใหม่ → ต้อง **ไม่เห็น** ข้อมูลบ้านของ A และ B

## ข้อควรรู้
- `anon key` ใส่ในหน้าเว็บได้ ความปลอดภัยมาจาก RLS ใน `schema.sql` ห้ามใส่ `service_role key` ในหน้าเว็บเด็ดขาด
- การไม่ยืนยันอีเมลทำให้สมัครง่าย แต่คนพิมพ์อีเมลผิดจะกู้รหัสผ่านไม่ได้ และอาจมีคนสมัครด้วยอีเมลคนอื่น ก่อนเปิดเก็บเงินควรเปิดยืนยันอีเมลกลับมา
- รุ่นแรก 1 บัญชีอยู่ได้ 1 บ้าน

## เฟส 2: เงินเดือน + OT + รอบตัด (อัปเดตแล้ว)
1. Supabase → SQL Editor → วาง `schema_phase2.sql` → Run (ไม่ลบข้อมูลเดิม)
2. อัปโหลด `index.html` ตัวใหม่ทับตัวเดิม (ค่า CONFIG ใส่ไว้ให้แล้ว)

กติกาการคำนวณ:
- ค่าจ้างรายชั่วโมง = เงินเดือน ÷ 30 ÷ 8 → OT 1.5 / 2 / 3 เท่า (หรือกรอกเรทเองในตั้งค่า)
- ขาดงาน/ลาไม่รับเงิน หักวันละ เงินเดือน ÷ 30 · ลาป่วย/ลากิจ/พักร้อน ไม่หัก
- รอบเดือน M ที่ตัด 21–20 = 21 ของเดือนก่อน ถึง 20 ของเดือน M
- ตั้งค่าที่บันทึกในเดือนไหน ใช้ตั้งแต่เดือนนั้นเป็นต้นไป เดือนก่อนหน้าไม่เปลี่ยน
- แก้ไขเงินเดือนได้เฉพาะเจ้าตัวหรือเจ้าของบ้าน คนอื่นในบ้านดูได้อย่างเดียว

## เฟสถัดไป
1. แก้ไขรายการ, งบประมาณรายหมวด, รายการประจำทุกเดือน
2. แผน Free / Pro + รับเงิน (PromptPay)
3. หน้านโยบายความเป็นส่วนตัว (PDPA), ลบบัญชี, ส่งออกข้อมูล

## เฟส 3: แดชบอร์ด, ค่ากะ, รายจ่ายหลัก, ยอดจริงตามสลิป, เรียลไทม์
1. Supabase → SQL Editor → วาง `schema_phase3.sql` → Run
2. อัปโหลด `index.html` ตัวใหม่ทับตัวเดิม

กติกาเพิ่มเติม:
- ค่ากะ: ตั้ง "ค่ากะ (บาท/วัน)" ในตั้งค่ารอบ แล้วเปิดสวิตช์ "มีค่ากะวันนี้" ในวันนั้น
- ภาพรวมคำนวณเงินเดือน + OT + ค่ากะของทุกคนให้อัตโนมัติ (ไม่ต้องบันทึกเป็นรายรับ)
- ถ้าบันทึก "ยอดจริงตามสลิป" ของรอบไหน ภาพรวมจะใช้ยอดจริงแทนยอดคำนวณ
- รายจ่ายหลักตั้งเป็นรายเดือน เดือนที่ไม่ได้ตั้งใช้ของเดือนก่อนหน้า อย่าบันทึกซ้ำในปุ่ม +
- มุมมองเดือน = แผนทั้งรอบ · ปี/ทั้งหมด = ถึงเดือนปัจจุบัน · วัน/สัปดาห์ = เงินเดือนเฉลี่ยรายวัน ถึงวันนี้
- รายรับเก่าที่ชื่อ "สลิปเงินเดือน รอบ ..." จากเฟส 2 จะไม่ถูกนับซ้ำ ลบทิ้งได้

## เฟส 4: ค่าจ้างรายวัน/รายเดือน, ภาพรวมเงินเดือนทั้งบ้าน, ล้างข้อมูล
1. Supabase → SQL Editor → วาง `schema_phase4.sql` → Run
2. อัปโหลด `index.html` ตัวใหม่ทับตัวเดิม

- รายเดือน: ได้เงินเดือนเต็มรอบ หักวัน "ขาด/ไม่รับเงิน" วันละ เงินเดือน ÷ 30 · OT/ชม. = เงินเดือน ÷ 240
- รายวัน: ได้ค่าแรงเฉพาะวันที่บันทึก "มาทำงาน" · OT/ชม. = ค่าแรงต่อวัน ÷ 8
- ปุ่มเฟืองมุมขวาบน → ล้างข้อมูลทั้งหมดในบ้าน (เฉพาะเจ้าของบ้าน ต้องพิมพ์ชื่อบ้านยืนยัน) บ้านและสมาชิกยังอยู่

## เฟส 5: จ่ายตามลำดับความสำคัญ, ธีม, รูปโปรไฟล์, รูปสลิป
1. Supabase → SQL Editor → วาง `schema_phase5.sql` → Run (สร้างที่เก็บไฟล์ `payslips` แบบส่วนตัวให้อัตโนมัติ)
2. อัปโหลด `index.html` ตัวใหม่ทับตัวเดิม

- แท็บเงินเดือน → ทั้งบ้าน: ไล่จ่ายรายจ่ายหลักทีละรายการตามลำดับ (↑ ↓ จัดลำดับในหน้าแก้ไข)
- ปุ่มเฟือง: ธีม (ตามเครื่อง/สว่าง/มืด จำไว้ในเครื่องนั้น), รูปและชื่อบ้าน (เจ้าของบ้าน), รูปและชื่อตัวเอง
- รูปสลิป: เจ้าตัว/เจ้าของบ้านแนบได้ · ทุกคนในบ้านดูได้ · คนนอกบ้านเปิดไม่ได้ (ลิงก์หมดอายุใน 1 ชม.)
- ความปลอดภัย: สมาชิกแก้ได้แค่ชื่อ/รูปตัวเอง เปลี่ยนสิทธิ์ตัวเองเป็นเจ้าของบ้านไม่ได้

## เฟส 6: ลบสมาชิก, แก้ยอดจริงย้อนหลัง, รายรับรายวัน, แท็บรับ–จ่าย, ฝากเงินเหลือ
1. Supabase → SQL Editor → วาง `schema_phase6.sql` → Run
2. อัปโหลด `index.html` ตัวใหม่ทับตัวเดิม

- บ้าน → สมาชิก: เจ้าของบ้านกด "ลบ" ได้ (ข้อมูลส่วนตัวของคนนั้นถูกลบ รายจ่ายใช้ร่วมกันย้ายมาเป็นของเจ้าของบ้าน)
- เงินเดือนรายคน → "ประวัติยอดจริง 12 รอบล่าสุด" กดแก้ไขรอบไหนก็ได้ พร้อมแนบ/เปลี่ยน/ลบรูปสลิป
- ตั้งค่ารอบนี้ → "รายรับรายวัน" (ยอดต่อวัน × จำนวนวันที่มาทำงาน)
- แท็บ "รับ–จ่าย": กราฟจากรายการที่บันทึก ดูได้ เดือน / ปี / ทั้งหมด
- เงินเดือน → ทั้งบ้าน: ถ้ามีเงินเหลือ กด "ฝากเงินคงเหลือ" → บันทึกเป็นรายรับหมวด "เงินฝากจากเงินเหลือ" (ไม่นับซ้ำในภาพรวม)
- แตะชื่อเดือน/วันที่ตรงกลางด้านบน เพื่อเลือกวันที่ที่จะดูได้ทันที ไม่ต้องกดเลื่อนทีละวัน

## เฟส 7: สิทธิ์รายคน, เปิด/ปิดฟังก์ชัน, กู้ยืม, ออกให้ก่อน, งบส่วนตัว, ภาพรวมใหม่
1. Supabase → SQL Editor → วาง `schema_phase7.sql` → Run
2. อัปโหลด `index.html` ตัวใหม่ทับตัวเดิม

- ปุ่มเฟือง = หน้าตั้งค่า (ธีม บ้าน โปรไฟล์ รหัสเชิญ สมาชิก+สิทธิ์ ฟังก์ชัน บัญชี ล้างข้อมูล)
- เมนูล่าง: ภาพรวม · รับ–จ่าย · + · เงินเดือน · ส่วนตัว
- รับ–จ่าย มี 3 หมวด: รับ–จ่าย / กู้ยืม / ออกให้ก่อน · ปัดซ้ายขวาที่ช่องเดือนด้านบน หรือแตะแถบเดือนเพื่อเลื่อนเร็ว
- ภาพรวม: เดือน/ปี/ทั้งหมด · เทียบรายรับรายจ่ายแต่ละเดือน/ปี · เงินเหลือโตขึ้นหรือลดลงจากเดือนก่อน/ปีที่แล้ว
- งบส่วนตัวเห็นเฉพาะเจ้าตัว (แม้แต่เจ้าของบ้านก็ไม่เห็น)

## เฟส 8: แยกไฟล์ + ติดตั้งเป็นแอป + ฟีเจอร์ใหม่
1. Supabase → SQL Editor → วาง `schema_phase8.sql` → Run
2. อัปโหลด **ทั้งโฟลเดอร์** ขึ้น Netlify (ลากโฟลเดอร์ไปวางที่ app.netlify.com/drop) ตอนนี้แอปมีหลายไฟล์แล้ว

โครงไฟล์:
- `index.html` หน้าเว็บ · `css/app.css` หน้าตา · `js/app.js` การทำงาน
- `js/config.js` **ค่า Supabase ของคุณ (แก้ที่ไฟล์นี้ไฟล์เดียว)**
- `manifest.webmanifest`, `sw.js`, `icons/` สำหรับติดตั้งเป็นแอปบนมือถือ
- `_headers` ให้ Netlify ไม่แคชไฟล์ sw.js

**ทุกครั้งที่อัปเดตไฟล์** ให้เปลี่ยน `VERSION` ใน `sw.js` (เช่น samudbaan-v9) เครื่องผู้ใช้จะได้ตัวใหม่ตอนเปิดแอปครั้งถัดไป

ติดตั้งบนมือถือ: Android (Chrome) → เมนู ⋮ → ติดตั้งแอป · iPhone (Safari) → ปุ่มแชร์ → เพิ่มไปยังหน้าจอโฮม
